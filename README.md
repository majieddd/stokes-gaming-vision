# Stokes Twins Gaming launch vision

Public working proposal, published at https://majieddd.github.io/stokes-gaming-vision/.

- `index.html`: full seven-chapter vision doc, 100 original ideas and the new Multiverse launch concept.
- `canvas.html`: 21 format rows, 105 thumbnail options (100 original episodes plus five variants of one new episode).
- Shared team feedback: each card has a GitHub issue. React with a thumbs-up to like it, or comment with a GitHub account. The canvas reads public counts and comments; it never stores account credentials. Public unauthenticated API limits can temporarily prevent refresh; the review links still work.
- Web images are high-quality JPEGs for the original 100 and original 4K PNGs for the five new variants. Exact original PNGs and selected prompts are in the launch-v1 release download.
- 001–055: built-in image generator, model unverified. 056–100 and MV-A–MV-E: verified Higgsfield GPT Image 2.5 Flare, 4K/high. These are generated concepts, not captured episode footage or verified cast photographs.
- Public evidence snapshots are dated October 5, 2026, with October 11 launch additions. No private CTR or retention curves were accessed. Cost allowances and outcomes are proposals, not approved funding or forecasts. New crossover mod compatibility is unverified.

The reusable blueprint/plugin is in `blueprint-plugin/`. Source videos, evidence limitations and title comparisons are preserved in the vision doc and JSON exports. Original user PDFs, workspace files, logs, secrets and provider media-library records are excluded.

## Hosting

GitHub Pages publishes the root of `main`. No build step, dependencies or server is required. Edits to static files can be reviewed and deployed through this repository. Team feedback is stored separately as GitHub issues and survives page changes.
